# Iron Law + 红旗清单（共享行为契约）

> buddy-hub 所有刚性 Skill 的统一头部模板。借鉴 Superpowers 的核心洞察：
> **目标不是教 Claude 规则（它本就懂），而是阻止 Claude 把自己说服去违反规则。**
> 每个刚性 Skill 必须在开头声明一条 IRON LAW，并附本文件的红旗词表。

## 如何使用

在 Skill 顶部加入：

```markdown
## ⚖️ IRON LAW（不可协商）
{一条全大写、单句、可判定真假的硬规则}

## 🚩 红旗清单（识别到这些念头/措辞，立即停手回到 IRON LAW）
{本 Skill 特定的开脱话术} + 引用下方「通用红旗词表」
```

## 通用红旗词表（所有 Skill 共享）

下列措辞一旦出现在你的推理或输出里，等同于你正在给自己找借口跳过纪律——**停手，回到 IRON LAW**：

| 红旗措辞 | 它真正的意思 | 正确动作 |
|----------|--------------|----------|
| "应该可以 / should / probably / 大概" | 你在猜，没验证 | 去跑、去证、去看实际输出 |
| "看起来对 / seems to / 看上去没问题" | 你在看，没验证 | 同上 |
| "就这一次 / 这次特殊 / 先这样" | 你在为破例铺垫 | 没有例外，按规则走 |
| "改动很小，不用 X" | 你在用规模换纪律 | 规模不豁免纪律 |
| "先留着旧代码做参考" | 你舍不得删 | 删掉，git 里有 |
| "测试首次就全过了" | 测试可能没真正在测 | 先让它失败，证明它有效 |
| "之后再补 X（测试/错误处理/文档）" | "之后"=永不 | 当下补齐 |
| "用户大概是想要…" | 你在替用户臆测 | 问清楚，或按已确认的来 |

## 违反时的自检

写出任何代码/结论前问自己三句：
1. 我是在**验证**，还是在**猜测**？
2. 我是否正在用上表里的某句话给自己开脱？
3. 这条 IRON LAW 此刻是否被我绕过了？

只要任一答案不对，停手。
